# Demos
Free starter sites. demo.mjs + addons.mjs.
- `example-bakery-demo/` — bakery starter site.
- `joes-plumbing/` — plumber starter site with the free rule-based chatbot widget added
  (`addons.mjs make chatbot ... --faq '[{"q":["emergency","24"],"a":"Yes, we offer 24/7 emergency service!"}]'`).
- `smoke/` — minimal CI smoke demo (must always pass the human-like test).
