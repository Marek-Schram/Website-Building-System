# Leads folder
One file per niche+city (e.g. `restaurant-st-charles.md`). Track opportunities found + outreach. Public info only.
Lodging leads (hotels/hostels/cabins/B&Bs/vacation rentals): `lodging-<city>.md`, written automatically by
`/find-booking-leads` — includes the detected booking system per property and the platform-presence evidence.
From a lodging lead: `/propose-lodging` → `/listing-kit` (docs/PROPOSALS.md, docs/LISTING-KIT.md).
